# Découverte courte et formations payantes

La version actuelle remplace le libre accès à 39 leçons par une seule découverte courte commune aux trois formations : une pause d'environ une minute, respiration naturelle et choix d'un petit geste pour soi.

Le catalogue public ne contient plus les anciens exercices complets. Il expose les bénéfices, les thèmes prévus et la découverte. La suite est un écran de présentation de l'accès payant ; aucune clé locale ou paramètre d'URL ne permet d'ouvrir un contenu complet.

Les modules détaillés seront créés ensuite. Aucun paiement ne peut être encaissé tant que les contenus complets, les conditions et le prestataire de paiement ne sont pas prêts. Les prix restent les achats uniques envisagés : 19, 39 et 69 euros. L'interface l'explique, sans simuler un achat.

Les futures leçons payantes devront être conservées sur un serveur et servies après vérification des droits. Un verrou visuel JavaScript sur GitHub Pages ne serait pas une protection suffisante. Ne jamais mettre le contenu payant dans le catalogue public ou dans un dépôt public.

Les bénéfices annoncés comprennent respiration et méditations guidées, déclinées par objectif. Ce sont des éléments prévus, pas des modules déjà livrés.

Lecture : choix automatique d'une voix française, priorité aux voix naturelles lorsqu'elles sont disponibles ; sélecteur de voix ; débit 0,82, volume 0,85. Le rendu dépend des voix installées dans le navigateur. L'enregistrement distant essayé était indisponible ; aucun MP3 vide ou fictif n'est publié.

Curseur : soleil SVG natif sur les appareils à souris ; curseur standard sur écran tactile.

Le stockage du nouveau carnet est séparé du précédent. L'effacement confirmé supprime aussi les anciennes données BOUM! présentes sur cet appareil.
