# MAMA — BOUM!

Site vitrine francophone consacré au développement personnel des femmes de 45 ans et plus.

## Structure

- `index.html` : contenu, navigation, quiz, témoignages, offres et FAQ.
- `styles.css` : identité graphique, mises en page adaptatives et animations.
- `script.js` : menu mobile, quiz à trois questions, bascule des tarifs, FAQ et effets visuels.

Le site est statique, sans dépendance de compilation. Les polices Fraunces et DM Sans sont chargées depuis Google Fonts.

## Aperçu local

Servir ce dossier avec un serveur HTTP statique, puis ouvrir `index.html` dans un navigateur.

## Publication

GitHub Pages publie automatiquement les trois fichiers du site à chaque mise à jour de `main`, via `.github/workflows/pages.yml`.

## État fonctionnel

Le quiz et les interactions fonctionnent dans le navigateur. Les boutons des formules mènent à la garantie : aucun paiement, inscription, réservation ou espace membre n'est connecté. Les liens des mentions légales, CGV, confidentialité et contact du pied de page sont encore des emplacements à compléter. Les chiffres, témoignages, garanties et l'adresse de contact sont le contenu fourni dans la maquette ; leur validation commerciale reste à faire.
